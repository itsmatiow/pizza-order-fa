# 🍕 Pizza Order

A modern pizza ordering website built with **React**, **Vite**, and **Tailwind CSS**.

The project simulates a real restaurant ordering experience where customers can browse the menu, add pizzas to their cart, place an order, and view their order details.

## ✨ Features

* Browse the pizza menu
* View pizza ingredients and prices
* Add and remove items from the cart
* Adjust item quantities
* Enter a table number before ordering
* Place orders
* View order details
* Calculate the total price
* Estimate preparation time
* Fully responsive design
* Persian RTL interface

## 🛠️ Tech Stack

* React
* JavaScript
* Vite
* Tailwind CSS
* React Router
* REST API

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/itsmatiow/pizza-order-fa.git
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Then open the local URL shown in your terminal.
